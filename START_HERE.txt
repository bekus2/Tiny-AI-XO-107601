ENGLISH
1. Extract the ZIP and open index.html in a modern browser. No installation.
2. New browsers start with the shared 185-game model. Existing local experience
   takes priority. Choose X/O, place marks, complete games and continue learning.
3. Five or more in a line wins; nine is a super win.
4. “Start self-play” starts self-play; press again to stop.
5. “Export my AI” exports your progress. Save it before reset or transfer.
6. “Import my AI” imports a JSON checkpoint after confirmation.
   Import model/checkpoint-185.json to restore the distributed starting model.
7. A confirmed reset starts a random zero-game model; export first.

This is educational AI, not an expert player. It improved against random moves
but still misses decisive blocks. Counters measure experience, not intelligence.
Internet, Python, Node, an account and an API key are not needed for play.
Use RU / EN at the top to switch languages without restarting the game.
A saved choice wins; otherwise the first supported browser language is used,
with English as fallback. The preference is separate from AI experience; if
its storage is blocked, it lasts until the current page is reloaded or closed.
Learning stays in this browser; storage may be cleared. Export regularly.

РУССКИЙ
1. Распакуйте ZIP и откройте index.html в современном браузере. Установка не нужна.
2. Новый браузер начнёт с опыта 185 партий. Сохранённый локальный опыт важнее.
   Выберите X/O, делайте ходы, завершайте партии и продолжайте обучение.
3. Пять и больше подряд — победа, девять — суперпобеда.
4. «ИИ играет сам» включает самоигру; повторное нажатие её останавливает.
5. «Скачать мой ИИ» сохраняет прогресс. Экспортируйте перед сбросом/переносом.
6. «Загрузить мой ИИ из файла» импортирует JSON после подтверждения.
   model/checkpoint-185.json возвращает модель из поставки.
7. Подтверждённый сброс создаёт случайную сеть с нулевым опытом.

Кнопки RU / EN вверху меняют язык без перезапуска игры. Сохранённый выбор
важнее языка браузера; иначе используется первый поддерживаемый язык браузера,
затем английский. Настройка отдельна от опыта; при запрете её хранения она
действует до перезагрузки или закрытия текущей страницы.

Это образовательный ИИ, не эксперт. Он стал сильнее против случайных ходов,
но по-прежнему пропускает решающие блокировки. Счётчики — опыт, не интеллект.
Для игры не нужны интернет, Python, Node, аккаунт или API-ключ.
Опыт остаётся в браузере, который может очистить данные. Скачивайте его регулярно.
