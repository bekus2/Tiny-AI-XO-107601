# Third-party notices / Сторонние компоненты

Tiny AI XO 107601 has no bundled third-party runtime dependencies, third-party pretrained weights, external AI provider, fonts, telemetry or game dataset. Its mathematical initialization and online learner are project code. The bundled 185-game checkpoint was produced by Beck Sarbassov through local play from random initialization; it is included for continued learning and educational experiments. Native browser APIs provide Worker, IndexedDB and optional localStorage. Python standard library assembles HTML; Node standard library runs engine tests. Chrome/Playwright used for development checks are not bundled or required to play. NumPy and the previous models/datasets are not included or required.

В поставку включён собственный чекпоинт Beck Sarbassov с опытом 185 локальных партий, обученный со случайной инициализации. Сторонних предобученных моделей, датасетов, внешнего ИИ и runtime-библиотек нет. Для игры нужен только браузер. Node/Python применяются исключительно при разработке/проверке. Предыдущие модели и их лицензии не включаются, поскольку их код/данные удалены из текущей поставки.

Developer documentation consulted: [IndexedDB](https://developer.mozilla.org/en-US/docs/Web/API/IndexedDB_API), [Web Workers](https://developer.mozilla.org/en-US/docs/Web/API/Web_Workers_API/Using_web_workers). No source text is copied into the application.
